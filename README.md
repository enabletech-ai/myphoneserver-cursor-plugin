# MyPhoneServer remote plugin

HTTPS endpoint: https://myphoneserver-mcp.enables-tech.workers.dev/mcp

Install this package using the product plugin UI or your organization marketplace. Authenticate in the client MCP connection UI, sign in to MyPhoneServer, select your phone and all services or selected services (including future services when desired), and approve on the phone. Older app-scoped connections keep their existing limits. No local MCP adapter, Node.js or npx is required.

The remote service operator and AI provider can read submitted source and logs. App service permissions do not establish filesystem isolation. Use the phone Connections screen to revoke only this connection. Existing PC connections and other product connections are separate.

An operator must deploy and verify the endpoint and register callbacks before distributing this generated package. Package generation alone does not establish a working connection.
